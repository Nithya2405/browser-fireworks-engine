# 🧠 Fireworks Engine Architecture

```
Rocket Launch
      │
      ▼
   Rocket Rise
      │
      ▼
   Trail Particles
      │
      ▼
Explosion Trigger
      │
      ▼
Particle Burst
      │
      ▼
Gravity + Fade
```

The animation loop is handled using **requestAnimationFrame**, ensuring smooth real-time rendering. 

The canvas is loaded from the main HTML entry file.

# ⚡ Quick Start

Clone the repository

```bash

```

Enter the folder

```bash

```

Open the project

```
open index.html
```

or simply **double click `index.html`**

# 🌈 Customization

### Change star count

```javascript
for(let i=0;i<200;i++)
```

### Change particle explosion size

```javascript
for(let i=0;i<120;i++)
```

### Change gravity strength

```javascript
this.vy += 0.05;
```
